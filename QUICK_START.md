# Quick Start Commands

# 1. Check current status
git status

# 2. Add your files
git add index.html style.css script.js

# 3. Commit with message
git commit -m "Add professional landing page with dynamic project showcase"

# 4. Push to GitHub
git push origin main

# 5. View deployment status
# Visit: https://github.com/JigsawFlux/jigsawflux.github.io/actions

# 6. View live site (wait 1-2 minutes after push)
# Visit: https://jigsawflux.github.io/

# 7. Make updates later
git add .
git commit -m "Update: [describe your changes]"
git push origin main
